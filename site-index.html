Aura

A configuration language that compiles to JSON, YAML and TOML. Schemas and assertions check the config before it ships; env() and read_file() are granted per run, and the grant never reaches what the manifest imports. 

enum Tier
  "frontend"
  "backend"
end

type Service
  name: String
  tier: Tier
  replicas: Int = 2
end

api: new Service
  name: "checkout-api"
  tier: "backend"
end
