# Блоки: `domain` и `component`

Конфиг редко бывает плоским. В Aura структуру задают **блоки** — они и группируют
значения, и создают область видимости. Блоков ровно два, и различаются они одним:
**куда попадает метка блока**.

| Форма | Метка становится | Где применяют |
| --- | --- | --- |
| `domain "prod" ... end` | **внешним ключом**: `"prod": {…}` | секции верхнего уровня, окружения |
| `component name ... end` | **полем внутри**: `{"name": …}` | элементы списков (обычно из `map`) |

## `domain` — именованная секция

Метка блока становится ключом объекта в выводе:

```ruby
domain "prod"
  replicas: 3
  region:   "eu-central"
end
```

```json
{
  "prod": {
    "replicas": 3,
    "region": "eu-central"
  }
}
```

Внутри блока действуют обычные правила `=` против `:`
(см. [Вычисления и вывод](bindings.md)): `key:` попадает в JSON, `=` остаётся
приватным вычислением.

## `component` — именованный элемент

Метка становится полем `name` **внутри** объекта, а не ключом снаружи. Поэтому
`component` удобен там, где каждый элемент списка несёт своё имя:

```ruby
services: ["api", "web"].map (n, i) ->
  component n
    port: 8000 + i
  end
end
```

```json
{
  "services": [
    { "name": "api", "port": 8000 },
    { "name": "web", "port": 8001 }
  ]
}
```

Метка `domain` — строка, а метка `component` может быть любым выражением
(здесь — параметр лямбды `n`). Это и делает генерацию списков через `map`
естественной: пишете один шаблон элемента вместо копипасты.

## Область видимости

Блок открывает новую область. Внешние переменные видны, но затенение требует
явного `shadow` (D7):

```ruby
port = 80

domain "prod"
  shadow port = 443 # без `shadow` — E0302
  listen: port      # 443
end

fallback: port # 80 — снаружи ничего не изменилось
```

Это прямой ответ на вопрос «почему в проде другой порт»: перекрытие значения
всегда видно в коде.

## Вложенность

Блоки вкладываются друг в друга, а простые вложенные объекты создаются обычным
`key:` с переводом строки (отдельного ключевого слова не нужно):

```ruby
domain "prod"
  security: # вложенный объект
    tls:     true
    ciphers: ["TLS_AES_256"]
  end

  domain "eu" # вложенный блок
    region: "frankfurt"
  end
end
```

```json
{
  "prod": {
    "security": { "tls": true, "ciphers": ["TLS_AES_256"] },
    "eu": { "region": "frankfurt" }
  }
}
```

## Что выбрать

- Нужен **раздел с именем** (окружение, кластер, крупная секция) → `domain`.
- Нужен **список однотипных объектов**, у каждого своё имя → `component` внутри
  `map`.
- Нужна просто **вложенная структура** без отдельного имени → `key:` … `end`.
