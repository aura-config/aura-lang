# Встроенные методы

Методы вызываются через точку и составляются в цепочки. Каждая сигнатура ниже
сверена с реализацией, а не переписана по памяти.

## String

| Метод | Результат | Примечания |
| --- | --- | --- |
| `upper()` / `lower()` | String | `"auth".upper()` → `"AUTH"` |
| `len()` | Int | считает символы: `"héllo".len()` → `5` |
| `trim()` | String | убирает пробельные символы по краям |
| `split(sep)` | List | `"a,b".split(",")` → `["a", "b"]` |
| `replace(from, to)` | String | все вхождения |
| `starts_with(prefix)` / `ends_with(suffix)` | Bool | |
| `contains(substr)` | Bool | `"hello".contains("ell")` → `true` |
| `to_int()` / `to_float()` | Int / Float | некорректное число — ошибка, а не `null` |
| `slice(start, end)` | String | подстрока по индексу **символа**, `end` не включается, индексы зажимаются |
| `to_str()` | String | тождество, чтобы не разрывать цепочку |
| `parse_json()` / `parse_yaml()` / `parse_toml()` | Object | целые становятся `Int`; сбой — `E0314` |
| ↳ точность | | порядок ключей — как в документе; YAML `<<` применяется; дата TOML становится `String` |
| `parse_duration()` | Int (секунды) | `"1h30m"` → `5400`; единицы `d/h/m/s`; `E0319` |
| `parse_datetime()` | Int (epoch UTC) | RFC 3339 или `YYYY-MM-DD`; смещения `±HH:MM`; `E0320` |
| `sha256()` | String | hex-дайджест в нижнем регистре |
| `base64()` / `base64_decode()` | String | стандартный алфавит с дополнением; неверный вход — `E0321` |

## List

| Метод | Результат | Примечания |
| --- | --- | --- |
| `len()` | Int | |
| `first()` / `last()` | элемент | пустой список — `E0317` |
| `get(i)` / `get(i, default)` | элемент | промах даёт `null` или указанный default |
| `contains(item)` | Bool | структурное равенство |
| `compact()` | List | убирает `null` |
| `uniq()` | List | дедупликация, порядок первых вхождений |
| `map (x, i) -> ... end` | List | колбэк получает элемент и его индекс |
| `filter (x, i) -> Bool end` | List | не-Bool из колбэка — `E0306` |
| `join(sep)` | String | только скаляры; контейнеры — `E0307` |
| `sort()` | List | |
| `reverse()` | List | |
| `sum()` | Int | |
| `min()` / `max()` | элемент | |
| `flatten()` | List | на один уровень: `[[1], [2, 3]]` → `[1, 2, 3]` |
| `to_object()` | Object | собирает объект из пар `{ key, value }`; повтор ключа — `E0323` |
| `reduce(init) (acc, e) -> … end` | Any | левая свёртка; начальное значение обязательно |
| `any (e, i) -> Bool end` | Bool | хотя бы один подходит; для пустого списка — `false` |
| `all (e, i) -> Bool end` | Bool | подходят все; для пустого списка — `true` |
| `find(default) (e, i) -> Bool end` | Any | первое совпадение или default |
| `index_of(value, default)` | Int | индекс первого равного элемента или default; default обязан быть `Int` |
| `slice(start, end)` | List | `end` не включается: `[1, 2, 3].slice(1, 3)` → `[2, 3]` |
| `to_json()` / `to_yaml()` / `to_toml()` | String | компактная форма, для встраивания; `to_toml` на списке — `E0603` |
| `to_json_pretty()` / `to_yaml_pretty()` / `to_toml_pretty()` | String | форма для человека, для файла, который попадает в diff |

## Операторы, которые строят значения

Почти все операторы числовые. Два — нет, и только у них результат может быть
больше того, что пришло на вход.

| Выражение | Результат | Примечания |
| --- | --- | --- |
| `"a" + "b"` | String | склеивает две строки; интерполяция `"#{a}#{b}"` делает то же самое |
| `[1] + [2, 3]` | List | склеивает два списка; операнды не меняются |

`+` никогда не преобразует. `"port " + 8080` — это `E0306`, и диагностика
называет сторону, на которой нужно вызвать `.to_str()`. Склейка ограничена
1 000 000 элементов списка и 16 МиБ строки, сообщается как `E0322`.

## Глобальные функции

| Функция | Требуемое право | Поведение |
| --- | --- | --- |
| `range(n)` | — | `[0, 1, … n-1]` |
| `env(name, default)` | `--allow-env` | переменная окружения; отсутствует → default |
| `read_file(path)` | `--allow-read` | содержимое файла строкой |
| `fail(message)` | — | останавливает выполнение с `E0531` и вашим сообщением |

Вызов метода имеет приоритет над одноимённым полем объекта, в котором лежит
функция. Экспортированные функции пакета вызываются тем же синтаксисом:
`pkg.fn(...)`.
